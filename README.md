# 🌟 Nhà Hàng Oriental Pearl | Tầng 66 Tòa Tháp Landmark 81
### Autograph Collection Hotels – Vinpearl Landmark 81, TP. Hồ Chí Minh

Trang thông tin, đặt bàn trực tuyến và hệ thống quản trị vận hành cao cấp của Nhà hàng **Oriental Pearl** – Trải nghiệm ẩm thực thượng đỉnh trên tầng 66 tòa tháp Landmark 81.

---

## 🏛️ Về Nhà Hàng Oriental Pearl
* **Vị trí:** Tầng 66, Tòa tháp Landmark 81, 720A Điện Biên Phủ, Phường 22, Bình Thạnh, TP. Hồ Chí Minh.
* **Món ăn biểu tượng:** **Phở Chọc Trời Bò Wagyu A4/A5**, Đại tiệc Buffet Tôm Hùm hảo hạng, Ẩm thực kết hợp Á - Âu đương đại.
* **Tầm nhìn:** Toàn cảnh 360 độ ngắm trọn sông Sài Gòn và hoàng hôn rực rỡ từ độ cao hơn 300 mét.

---

## 🚀 Tính Năng Nổi Bật

### 1. Trải Nghiệm Thực Khách (Guest Experience)
- **Thiết kế sang trọng chuẩn 5 sao:** Tone màu Alabaster White, Ivory Cream và Royal Gold quý phái.
- **Hệ thống Đặt bàn Trực tuyến:** Đặt chỗ từng bước với máy tính ước lượng chi phí tự động.
- **Thanh toán VietQR Động:** Tự động sinh mã QR chuyển khoản với số tài khoản, mã đơn đặt chỗ và số tiền cọc chính xác.
- **Biên nhận & Email Xác nhận:** Xuất biên nhận điện tử có thể in hoặc lưu trữ tức thì.
- **AI Chatbot "Cô Lễ Tân Ảo":** Trợ lý ảo tư vấn thực đơn, món ăn và hỗ trợ đặt chỗ 24/7.
- **Đa kênh liên hệ:** Tích hợp gọi Hotline trực tiếp (`0911 817 033`), Zalo, WhatsApp quốc tế, Facebook Messenger.

### 2. Cổng Quản Trị Hệ Thống (Integrated Admin Portal)
- **Kiến trúc 2-in-1:** Chuyển đổi linh hoạt giữa Guest View và Admin Portal ngay trên một tệp duy nhất.
- **Theo dõi thời gian thực (Real-time Analytics):** Giám sát doanh thu, tổng số đơn đặt bàn, tỷ lệ chuyển đổi và số lượt truy cập.
- **Phân quyền người dùng:** Tài khoản Main Admin quản lý và phân quyền cho các Sub-Admins (Lễ tân/Nhân viên trực bàn).
- **Xuất dữ liệu:** Hỗ trợ trích xuất toàn bộ danh sách đặt chỗ ra file định dạng CSV/Excel.
- **Đồng bộ Đám mây Firebase:** Hỗ trợ kết nối Cloud Firestore để đồng bộ hóa dữ liệu đặt bàn đa thiết bị theo thời gian thực.

## 🛠️ Công Nghệ Sử Dụng (Tech Stack)
* **Frontend:** HTML5, Tailwind CSS (CDN), Google Fonts (Cormorant Garamond & Plus Jakarta Sans), FontAwesome 6, Lucide Icons.
* **Cơ sở dữ liệu Đám mây:** Google Firebase Cloud Firestore / Realtime Database (với cơ chế Fallback LocalStorage).
* **Quản lý mã nguồn:** Git & GitHub Repository.
* **Triển khai & Hosting:** Vercel Edge Network (Global CDN, SSL/HTTPS tự động).

## 📦 Hướng Dẫn Triển Khai Lên Vercel
1. Đẩy mã nguồn dự án lên GitHub Repository của bạn.
2. Truy cập [Vercel](https://vercel.com/) và chọn **Add New Project**.
3. Import GitHub repository này và bấm **Deploy**.
4. Website sẽ trực tuyến trong vòng vài giây với chứng chỉ bảo mật SSL miễn phí.
